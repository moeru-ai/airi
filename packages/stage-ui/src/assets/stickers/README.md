# Chat stickers

These bundled images come from [Microsoft Fluent Emoji](https://github.com/microsoft/fluentui-emoji/tree/main/assets).
The MIT license is in `LICENSE-fluent-emoji.txt`. The images are unchanged.

| File | Original asset folder | Style |
| --- | --- | --- |
| `cat-laugh.png` | Cat with tears of joy | 3D |
| `cat-wow.png` | Weary cat | 3D |
| `dog.png` | Dog face | 3D |
| `heart.png` | Red heart | 3D |

The model selects an ID from `index.ts`. It cannot provide an image URL.
