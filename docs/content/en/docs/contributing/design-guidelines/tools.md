## Colors


By default, during development we use a tool called [UnoCSS](https://unocss.dev) to help us generate everything related to stylesheets. It is a great tool that works exactly like [Tailwind](https://tailwindcss.com).


Therefore, the basic color palette is listed under [Colors - Core concepts - Tailwind CSS](https://tailwindcss.com/docs/colors).


In general, we use `neutral`, `pink`, `violet`, and `cyan` as the default theme. Both [UnoCSS](https://unocss.dev) and [Tailwind](https://tailwindcss.com) support color-based opacity adjustments, but according to [Refactoring UI](https://refactoringui.com/):


> Whenever we want to change the chroma of a color, we should try to avoid using opacity and instead manually pick the best solid color without an alpha channel for the best contrast.


So, unless opacity is part of the typographic design, try to pick the best solid color for better readability.


Another great tool we use is called [Radix Colors](https://www.radix-ui.com/colors). It is a bit like the building blocks for our interactive UI elements, because they build excellent palettes that support sound color theory; you can also pick suitable colors from the palette.


You may already know what _complementary colors_ are; they are useful for color contrast. Here are a few good tools to help you quickly and interactively pick complementary colors:


- [Color wheel - Figma](https://www.figma.com/color-wheel/)
- [Color wheel - Canva Colors](https://www.canva.com/colors/color-wheel/)
- [Paletton](https://paletton.com/#uid=55v1e0kk-p26VFOfrvbqEdSDDbg)
