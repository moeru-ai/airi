### yui540


One of the greatest CSS scene-transition authors I know is **[yui540](https://yui540.com/)**, who has designed many other stunning-looking ACG websites, most notably [臆病な魔女](https://cowardly-witch.netlify.app/) (the source code can be found under [yui540](https://github.com/yui540?tab=repositories)).


To implement transitions similar to the ones above, you can refer to this repository: [yui540/css-animations: 俺流CSSアニメーション](https://github.com/yui540/css-animations)
