title: BytePlus Coding Plan
description: Configure BytePlus Coding Plan chat models in AIRI
---


BytePlus Coding Plan is offered as a dedicated provider card in AIRI.


::: info Why choose BytePlus Coding Plan?


If your BytePlus account has the Coding Plan enabled, you should use this card instead of the regular BytePlus configuration to match the corresponding service plan.


:::


## Step 1: Prepare BytePlus Coding Plan Credentials


1. Open and sign in to the [BytePlus Console](https://console.byteplus.com/) and obtain the credentials and endpoint information from the Coding Plan pages.


::: warning API Key Security


Do not commit the API key or endpoint credentials to the repository, put them in screenshots, or share them with others.


:::


## Step 2: Configure in AIRI


1. Open **Settings → Providers → Chat → BytePlus Coding Plan** and fill in the plan's credentials and endpoint information per the BytePlus console.


## Step 3: Verify the Configuration


1. **Ping API**: click this button to test the network and whether the credentials are correct.
2. **Select Model**: after the test succeeds, select an available model under **Settings → Consciousness**.


## Troubleshooting


If verification fails, check that the credentials and endpoint belong to the same BytePlus Coding Plan. If models cannot be loaded, confirm the plan has access to the target model enabled.
