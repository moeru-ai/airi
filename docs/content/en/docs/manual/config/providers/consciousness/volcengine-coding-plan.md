---
title: Volcengine Coding Plan
description: Configure Volcengine Coding Plan chat models in AIRI
---


Volcengine Coding Plan is offered as a dedicated provider card in AIRI.


::: info Why choose Volcengine Coding Plan?


If your account uses the Volcengine Coding Plan, you should select this card to match the corresponding service plan.


:::


## Step 1: Prepare Coding Plan Credentials


1. Open and sign in to the [Volcengine console](https://console.volcengine.com/) and obtain the API key, endpoint, and model information from the Coding Plan pages.


::: warning API Key Security


Do not commit the API key or endpoint credentials to the repository, put them in screenshots, or share them with others.


:::


## Step 2: Configure in AIRI


1. Open **Settings → Providers → Chat → Volcengine Coding Plan** and fill in the plan's API key, endpoint, and model information per the Volcengine console.


## Step 3: Verify the Configuration


1. **Ping API**: click this button to test the network and whether the credentials are correct.
2. **Select Model**: after the test succeeds, select an available model under **Settings → Consciousness**.


## Troubleshooting


If verification fails, check that the API key, endpoint, and model information belong to the same Volcengine Coding Plan. If models cannot be loaded, confirm the plan has access to the target model enabled.
