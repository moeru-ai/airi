---
title: AIRI Official Provider
description: Use AIRI Official as your chat provider
---


If you want to get started with AIRI quickly and simplify configuration, you can use the official provider to start chatting.


::: info Why choose the AIRI official provider?


If you want a quick AIRI experience without configuring a third-party API key yourself, you can select the official provider.


:::


## Step 1: Sign In


1. Click the sign-in button; a browser page will open.
2. Choose a sign-in method. We currently support email, Google, and GitHub sign-in.


    ::: info Note for users in China


    Users in China may not be able to sign in with Google or GitHub. Please use email sign-in. Phone-number registration/sign-in is not supported yet.


    :::


3. Complete sign-in/registration as prompted.


    ::: info


    If you do not receive the email, check whether it was moved to spam.


    :::


## Step 2: Check Available Credits


Every new account has 150 credits. Each conversation consumes some credits; once they run out, you cannot continue chatting for the time being.


## Step 3: Top Up Credits


Topping up is currently only supported on the AIRI web version. After signing in to the web version, open **Settings → Flux**, select a credit package, and complete the payment as prompted. The desktop version does not support direct top-ups yet.


## Troubleshooting


If you do not receive the sign-in email, check the spam folder. If the web version cannot show available credit packages or cannot create a payment, try again later; when you need to top up on the desktop version, go to the AIRI web version to complete the operation.
