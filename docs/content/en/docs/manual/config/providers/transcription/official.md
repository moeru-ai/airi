---
title: AIRI Official Speech Recognition (ASR/STT)
description: Use the official real-time speech recognition in AIRI
---


The official speech recognition uses your AIRI sign-in status and does not require a separate third-party API key.


::: info Why choose AIRI official speech recognition?


If you already use the AIRI official provider and want to enable real-time voice input quickly, you may want to try this option first.


:::


## Step 1: Sign In


1. Sign in with your AIRI account; the official real-time recognition depends on the current sign-in state.
2. No need to create or fill in a third-party API key.


::: warning Account and Audio Data


Real-time recognition sends audio to the official service. Do not use test audio containing sensitive information, and do not share account session information.


:::


## Step 2: Configure in AIRI


1. Open **Settings → Providers → Speech Recognition → AIRI Official Speech Recognition**.
2. Select `Auto` or a model provided by the server, then enable it under **Settings → Hearing**.


## Step 3: Verify the Configuration


1. Allow AIRI to use the microphone and do a short voice input.
2. If the transcribed text is displayed, the configuration was successful.


## Troubleshooting


If a model cannot be used, confirm the account is signed in, the network works, and there are available credits. If there are no text results, check the system's microphone permission.
