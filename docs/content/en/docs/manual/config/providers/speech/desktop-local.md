---
title: Desktop Local Text-to-Speech (TTS)
description: Use local text-to-speech in the AIRI desktop client
---


Desktop-local text-to-speech is only available in the AIRI desktop client and does not require a cloud API key.


::: info Why choose desktop-local text-to-speech?


If you use the AIRI desktop client and want to reduce reliance on cloud TTS, you can select this option.


:::


## Step 1: Confirm the Desktop Environment


1. Use the AIRI desktop client; this provider does not appear on the web client.
2. Ensure the device has enough disk space and computing resources for the local model.


::: warning Runtime Environment


This provider does not appear on the web client. Running the model uses local disk and computing resources.


:::


## Step 2: Configure in AIRI


1. Open **Settings → Providers → Speech → App (Local)** in the AIRI desktop client.
2. Select an available model and voice; once ready, enable it under **Settings → Speech**.


## Step 3: Verify the Configuration


1. Enter a short text and preview it.
2. If the speech plays normally, the configuration was successful.


## Troubleshooting


If the provider does not appear, confirm you are running the desktop client. If model preparation fails, check disk space and device resources, then retry.
