---
title: AIRI Official Text-to-Speech (TTS)
description: Use the official text-to-speech in AIRI
---


The official text-to-speech uses your AIRI sign-in status and does not require a separate third-party API key.


::: info Why choose AIRI official text-to-speech?


If you already use the AIRI official provider and want to reduce third-party credential configuration, you may want to try this option first.


:::


## Step 1: Sign In


1. Sign in with your AIRI account; the official speech service depends on the current sign-in state.
2. No need to create or fill in a third-party API key.


::: warning Account and Credits


The available models, credits, and regions of the official service are determined by the server. Do not share your account sign-in state or browser session information.


:::


## Step 2: Configure in AIRI


1. Open **Settings → Providers → Text-to-Speech → AIRI Official Text-to-Speech**.
2. Wait for AIRI to load the currently available models and voices from the server.


## Step 3: Verify the Configuration


1. Select a model and voice under **Settings → Speech**, then preview with short text.
2. If it plays normally, the configuration was successful. If the server does not provide streaming speech, the streaming option will not appear.


## Troubleshooting


If the model list cannot be loaded, confirm the account is signed in, the network works, and there are available credits. If the desktop client cannot top up, go to **Settings → Flux** on the AIRI web client to complete the payment.
