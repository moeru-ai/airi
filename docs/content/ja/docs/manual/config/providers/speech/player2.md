---
title: Player2 Speech（TTS）
description: AIRI のローカル Player2 Speech サービスに接続する
---

Player2 Speech は、ローカル サービス経由で接続される音声合成オプションです。

::: info Player2 Speech を選択する理由
Player2 Speech をローカルまたは信頼できる LAN 上ですでに実行している場合は、AIRI をサービスに接続して、サービスが提供するVoiceを読み取ることができます。
:::

## ステップ 1: ローカル サービスを開始する

1. Player2 Speech サービスを開始し、ヘルスチェックが利用可能であることを確認します。
2. AIRI はデフォルトで `http://localhost:4315/v1/` に接続します。サービスが別のアドレスで実行されている場合は、完全なベース URL を記録してください。

::: warning ローカルサービスのセキュリティを警告する
ローカル サービス ポートを信頼できないパブリック ネットワークに公開しないでください。
:::

## ステップ 2: AIRI で設定する

1. **[設定] → [プロバイダー] → [Speech] → [Player2 音声]** を開きます。
2. サービス アドレスと一致するベース URL を入力します。

## ステップ 3: 構成を確認する

1. プロバイダー設定でモデルと利用可能な音声を選択します。
2. 同じページのプレイグラウンドで短いテキストを入力し、音声が再生されることを確認します。

## AIRI の返信で有効にする

**設定 → モジュール → 音声**を開き、**Player2 Speech**、モデル ID `player2-tts`、Voice を選択します。プロバイダーのテストだけでは、通常の返信に音声は適用されません。

## トラブルシューティング

接続に失敗した場合は、サービスの `/health` 応答とベース URL を確認してください。Voice リストが空の場合は、サービスの `/tts/voices` インターフェイスにアクセスできることを確認します。
