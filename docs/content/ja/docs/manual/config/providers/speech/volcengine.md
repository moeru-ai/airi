---
title: Volcengine (TTS)
description: AIRI での Volcano Engine 音声合成の設定
---

Volcano エンジン音声合成では、API キーとアプリケーション情報を AIRI に入力する必要があります。

::: info ボルケーノ エンジンを選ぶ理由
Volcano Engine で音声アプリケーションを作成し、Voice リソースを管理している場合は、この設定セットを AIRI で再利用できます。
:::

## ステップ 1: アプリケーションの資格情報を準備する

1. [Volcengine Console](https://console.volcengine.com/) で音声合成サービスを有効にし、音声アプリケーションを作成します。
2. アプリケーションの **アプリ ID** をコピーし、対応する **API キー**を作成します。
3. 両方の情報が同じアカウントとアプリケーション構成からのものであることを確認します。

::: warning API キーのセキュリティ
API キーまたはアプリ ID に対応する認証情報を開示しないでください。漏洩後は、プロバイダー コンソールのキーを直ちに交換してください。
:::

## ステップ 2: AIRI で設定する

1. **設定 → プロバイダー → Speech → Volcengine**を開きます。
2. API キーと App ID を入力します。デフォルトのベース URL `https://unspeech.hyp3r.link/v1/` は Volcengine の直接 API ではなく、AIRI/UnSpeech ゲートウェイです。認証情報、合成するテキスト、モデル/Voice の選択、返される音声がこのゲートウェイを経由します。許容できない場合は互換性のあるセルフホストゲートウェイを入力するか、直接接続するプロバイダーを選択します。

## ステップ 3: 構成を確認する

1. プロバイダー設定でモデルと利用可能な音声を選択します。
2. 同じページのプレイグラウンドで短いテキストを入力し、音声が再生されることを確認します。

## AIRI の返信で有効にする

**設定 → モジュール → 音声**を開き、**Volcengine**、利用可能なモデル、Voice を選択します。プレイグラウンドは認証情報のテスト用であり、このモジュール選択によって通常の返信で音声が有効になります。

## トラブルシューティング

検証に失敗した場合は、アプリ ID と API キーが同じアプリケーションのものであるかどうかを確認してください。音が出ない場合は、アプリで音声合成が有効になっていてVoiceが選択されていることを確認してください。
