---
title: Microsoft Azure Speech（TTS）
description: AIRI での Microsoft Azure 音声合成の設定
---

Microsoft Azure Speech は、AIRI で Azure 音声合成機能を提供します。

::: info Microsoft Azure Speech を選択する理由
チームが既に Azure で音声リソースとリージョン構成を管理している場合は、同じ資格情報を使用する方が便利です。
:::

## ステップ 1: Azure Speech リソースを準備する

1. [Azure Portal](https://portal.azure.com/) で Speech リソースを作成し、音声サービスが利用できるリージョンを選択します。
2. **API キー**とリソースのリージョンを記録します。両方とも同じ音声リソースからのものである必要があります。
3. キーをコピーし、安全な場所に保管します。

::: warning API キーのセキュリティ
Azure キーを使用すると、音声リソースへのアクセスが可能になります。送信したり、スクリーンショットを撮ったり、共有したりしないでください。
:::

## ステップ 2: AIRI で設定する

1. **設定 → プロバイダー → Speech → Microsoft / Azure Speech**を開きます。
2. API キーとリージョンを入力します。デフォルトのベース URL `https://unspeech.hyp3r.link/v1/` は Azure の直接 API ではなく、AIRI/UnSpeech ゲートウェイです。認証情報、リージョン、合成するテキスト、Voice の選択、返される音声がこのゲートウェイを経由します。許容できない場合は互換性のあるセルフホストゲートウェイを入力するか、直接接続するプロバイダーを選択します。

## ステップ 3: 構成を確認する

1. プロバイダー設定でモデルと利用可能な音声を選択します。
2. 同じページのプレイグラウンドで短いテキストを入力し、音声が再生されることを確認します。

## AIRI の返信で有効にする

**設定 → モジュール → 音声**を開き、**Microsoft / Azure Speech**、利用可能なモデル、Voice を選択します。プレイグラウンドは認証情報のテスト用であり、このモジュール選択によって通常の返信で音声が有効になります。

## トラブルシューティング

検証が失敗した場合は、領域が Speech リソースと一致しているかどうかを確認することが優先されます。音声がない場合は、「音声」で音声が選択されていることを確認し、リソースに使用可能なクレジットがあるかどうかを確認してください。
