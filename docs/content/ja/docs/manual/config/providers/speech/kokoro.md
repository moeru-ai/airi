---
title: こころ（ローカルTTS）
description: AIRI でローカル Kokoro 音声合成を設定する
---

Kokoro は AIRI 内でローカルに音声合成を実行します。

::: info なぜKokoroを選ぶのか？
音声コンテンツをローカルで処理する必要があり、デバイスがモデルの実行条件を満たしている場合は、Kokoro を選択できます。
:::

## ステップ 1: ローカルの動作環境を準備する

1. AIRI を開き、初回はモデルのダウンロードが完了するまで待ちます。
2. WebGPU を利用できる場合は音声合成を高速化できます。WebGPU がなくても WASM にフォールバックできますが、通常は処理が遅くなり、CPU 使用量が増えます。
3. クラウド API キーは不要ですが、ローカルストレージ、メモリ、計算資源を使用します。

::: warning ローカルリソースの使用状況を警告する
ローカル モデルは、ダウンロード スペース、メモリ、およびコンピューティング リソースを占有します。デバイスのリソースが不足している場合は、強制的に有効化しないでください。
:::

## ステップ 2: AIRI で設定する

1. **設定 → プロバイダー → Speech → Kokoro**を開きます。
2. AIRI が提供する利用可能な Kokoro モデルを選択します。

## ステップ 3: 構成を確認する

1. **モデルと Voice の選択**: モデルを準備したら Voice を選択し、**設定 → モジュール → 音声**で有効にします。
2. 聞く短いテキストを入力します。正常に再生できれば、モデルの準備が完了したことを意味します。

## トラブルシューティング

モデルを読み込めない場合は、ストレージとメモリの空きを確認し、ページを開き直してダウンロード完了まで待ちます。WebGPU を利用できない場合は、WASM の初期化と音声合成に時間がかかることがあります。
