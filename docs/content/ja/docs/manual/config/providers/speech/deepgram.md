---
title: Deepgram（TTS）
description: AIRI でのDeepgram音声合成の設定
---

Deepgram は、AIRI で音声合成モデルの Aura ファミリを提供します。

::: info Deepgramを選ぶ理由
すでに Deepgram を使用している場合、または Aura の音声範囲から選択したい場合は、この統合を使用できます。
:::

## ステップ 1: API キーを取得する

1. [Deepgram Console](https://console.deepgram.com/) を開いてログインし、必要な API キーまたは認証情報を作成します。
2. プロジェクトに音声合成の使用権限があることを確認します。
3. キーをコピーし、安全な場所に保管します。

::: warning API キーのセキュリティ
API キーをリポジトリに送信したり、スクリーンショットを撮ったり、他の人に送信したりしないでください。
:::

## ステップ 2: AIRI で設定する

1. **設定 → プロバイダー → Speech → Deepgram**を開き、API キーを入力します。
2. デフォルトのベース URL `https://unspeech.hyp3r.link/v1/` は Deepgram の直接 API ではなく、AIRI/UnSpeech ゲートウェイです。API キー、合成するテキスト、モデル/Voice の選択、返される音声がこのゲートウェイを経由します。この信頼境界を許容する場合だけ使用してください。それ以外は互換性のあるセルフホストゲートウェイを入力するか、直接接続するプロバイダーを選択します。

## ステップ 3: 構成を確認する

1. プロバイダー設定でモデルと利用可能な音声を選択します。
2. 同じページのプレイグラウンドで短いテキストを入力し、音声が再生されることを確認します。

## AIRI の返信で有効にする

**設定 → モジュール → 音声**を開き、**Deepgram**、利用可能なモデル、Voice を選択します。プレイグラウンドのテストだけでは、通常の返信に音声は適用されません。

## トラブルシューティング

プレイグラウンドでリクエストが完了しない場合は、プロジェクトの API キー、アカウントの権限、ネットワーク接続を確認してください。Voice リストが空の場合は、モデルを選択する前に認証情報を再テストしてください。
