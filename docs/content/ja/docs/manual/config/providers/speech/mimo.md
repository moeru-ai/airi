MiMo は、プリセット Voice、Voice デザイン、Voice クローンの 3 つの音声合成モードをサポートしています。

::: info Xiaomi MiMo を選ぶ理由?
中国語のVoiceをプリセットする必要がある場合、またはテキストの説明を使用してVoiceをデザインしたい場合は、MiMo を選択できます。
:::

## ステップ 1: API キーを取得する

1. [Xiaomi MiMo Platform](https://platform.xiaomimimo.com/) で API アクセスを有効にし、使用する音声モデルへのアクセスを確認します。
2. API キーを作成し、コピーして安全な場所に保管します。

::: warning 音サンプルとAPI Keyセキュリティ
Voice のクローン作成には、Base64 データ URI 形式の音声サンプルが必要です。使用許可のある Voice のみをアップロードしてください。API キーや他の人の Voice サンプルを公開しないでください。
:::

## ステップ 2: AIRI で設定する

1. **[設定] → [プロバイダー] → [Speech] → [Xiaomi MiMo]** に API キーを入力します。
2. プロバイダーが別のアドレスを提供しない限り、デフォルトのベース URL: `https://api.xiaomimimo.com/v1/` を維持します。

## ステップ 3: 構成を確認する

1. プロバイダー設定でモデルと利用可能な音声を選択します。
2. 同じページのプレイグラウンドで短いテキストを入力し、音声が再生されることを確認します。

## AIRI の返信で有効にする

**設定 → モジュール → 音声**を開き、**Xiaomi MiMo**、モデル ID `mimo-v2-omni`、Voice を選択します。プロバイダーのテストだけでは、通常の返信に音声は適用されません。

## トラブルシューティング

リクエストが失敗した場合は、API キーとモデルの選択を確認してください。Voice のクローン作成が失敗した場合は、サンプルが有効な Base64 データ URI であること、および Voice を使用する権限があることを確認してください。
