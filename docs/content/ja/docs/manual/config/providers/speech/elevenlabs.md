---
title: ElevenLabs（TTS）
description: AIRI での ElevenLabs 音声合成の設定
---

ElevenLabsは AIRI の応答を音声に合成します。

::: info ElevenLabsを選ぶ理由?
ElevenLabs アカウントのVoiceを使用し、利用可能なVoiceを AIRI で直接選択する場合は、このプロバイダーを選択します。
:::

## ステップ 1: API キーを取得する

1. [ElevenLabsAPIキー設定](https://elevenlabs.io/app/settings/api-keys) を開いてログインし、必要な API キーまたは認証情報を作成します。
2. キーに識別しやすい名前と適切な使用制限を付けます。
3. キーをコピーし、安全な場所に保管します。

::: warning API キーのセキュリティ
API キーをリポジトリに送信したり、スクリーンショットを撮ったり、他の人に送信したりしないでください。リークが疑われる場合は、直ちに取り消して、ElevenLabs コンソールで再作成してください。
:::

## ステップ 2: AIRI で設定する

1. **設定 → プロバイダー → Speech → ElevenLabs**を開きます。
2. API キーを基本設定に貼り付けます。
3. デフォルトのベース URL `https://unspeech.hyp3r.link/v1/` は ElevenLabs の直接 API ではなく、AIRI/UnSpeech ゲートウェイです。API キー、合成するテキスト、モデル/Voice の選択、返される音声がこのゲートウェイを経由します。この信頼境界を許容する場合だけ使用してください。それ以外は互換性のあるセルフホストゲートウェイを入力するか、直接接続するプロバイダーを選択します。

## ステップ 3: 構成を確認する

1. プロバイダー設定でモデルと利用可能な音声を選択します。
2. 同じページのプレイグラウンドで短いテキストを入力し、音声が再生されることを確認します。

## AIRI の返信で有効にする

**設定 → モジュール → 音声**を開き、**ElevenLabs**、利用可能なモデル、Voice を選択します。プレイグラウンドのテストだけでは、通常の返信に音声は適用されません。

## トラブルシューティング

プレイグラウンドでリクエストが完了しない場合は、API キー、アカウント制限、ネットワーク接続を確認してください。モデルは表示されるのに音が鳴らない場合は、「音声」で有効なモデルと音が選択されているか確認してください。
