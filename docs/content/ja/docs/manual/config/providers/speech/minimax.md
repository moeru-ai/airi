---
title: MiniMax Speech（TTS）
description: AIRI での MiniMax 音声合成の設定
---

MiniMax Speech は、AIRI に音声合成モデルとプリセットVoiceを提供します。

::: info MiniMax Speech を選択する理由
すでに MiniMax を使用していて、その中国語または英語のプリセット Voiceを直接使用したい場合は、それを選択できます。
:::

## ステップ 1: API キーを取得する

1. [MiniMax Global Platform](https://platform.minimax.io/) で音声サービスを有効にし、使用するモデルへのアクセスを確認します。
2. APIキー管理ページでキーを作成します。
3. キーをコピーし、安全な場所に保管します。

::: warning API キーのセキュリティ
API キーをリポジトリに送信したり、スクリーンショットを撮ったり、他の人に送信したりしないでください。
:::

## ステップ 2: AIRI で設定する

1. **[設定] → [プロバイダー] → [Speech] → [MiniMax Speech]** を開き、API キーを貼り付けます。
2. グローバル版のサービスアドレス `https://api.minimax.io` を使用します。`platform.minimaxi.com` で発行した認証情報は中国向けサービスに属するため、そのプラットフォームに記載されたエンドポイントを使用してください。

## ステップ 3: 構成を確認する

1. プロバイダー設定でモデルと利用可能な音声を選択します。
2. 同じページのプレイグラウンドで短いテキストを入力し、音声が再生されることを確認します。

## AIRI の返信で有効にする

**設定 → モジュール → 音声**を開き、**MiniMax Speech**、`speech-2.8-hd` または `speech-2.8-turbo`、利用可能な Voice を選択します。プロバイダーのテストだけでは、通常の返信に音声は適用されません。

## トラブルシューティング

プレイグラウンドでリクエストが完了しない場合は、API キー、アカウント制限、ネットワーク接続を確認してください。モデルまたはVoiceが利用できない場合は、MiniMax アカウントで現在開いているリストが優先されます。
