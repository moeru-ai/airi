Moonshot は、OpenAI 形式と互換性のあるチャット API を提供します。このページでの設定を完了すると、AIRI は Moonshot が提供するモデルを 意識 で使用できるようになります。

::: info Moonshotを選ぶ理由
AIRI で Moonshot モデルを使用する場合、またはすでに Moonshot API キーを持っている場合は、このプロバイダーを直接選択できます。
:::

## ステップ 1: API キーを取得する

1. [Moonshot Global Console](https://platform.moonshot.ai/)を開いてログインし、API キーを作成します。
2. [API キー] ページで新しい API キーを作成します。
3. キーをコピーし、安全な場所に保管します。

::: warning API キーのセキュリティ
API キーをリポジトリに送信したり、スクリーンショットを含めたり、他の人に送信したりしないでください。キーが侵害されたら、すぐにそれを取り消して、Moonshot コンソールで新しいキーを作成します。
:::

## ステップ 2: AIRI で設定する

1. **[設定] → [プロバイダー] → [チャット] → [Moonshot]** を開きます。
2. API キーを基本設定に貼り付けます。
3. グローバル版のベース URL `https://api.moonshot.ai/v1/` を使用します。`platform.moonshot.cn` で発行したキーは、そのコンソールに記載された中国向けエンドポイントと組み合わせてください。異なるリージョンの認証情報とエンドポイントは混在できません。

## ステップ 3: 構成を確認する

1. **検証**: 設定を保存し、プロバイダーページに表示される検証を実行します。その後、**設定 → モジュール → 意識**でプロバイダーとモデルを選択し、テストメッセージを送信します。
2. **モデルの選択**: テストが成功したら、ここをクリックして使用する特定のモデルを選択します。

## トラブルシューティング

API への ping が失敗した場合は、API キー、アカウント制限、ネットワーク接続を確認してください。モデル リストのロードに失敗した場合は、Moonshot によって提供される正確なモデル ID を [意識] ページに手動で入力できます。
