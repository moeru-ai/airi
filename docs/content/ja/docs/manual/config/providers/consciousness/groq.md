Groq は、OpenAI 形式と互換性のあるチャット API を提供します。このページでの設定を完了すると、AIRI は、Groq が提供するモデルを 意識 で使用できるようになります。

::: info Groq を選ぶ理由?
会話の応答性を重視し、ターゲット モデルが Groq で利用できる場合は、このプロバイダーを試してください。
:::

## ステップ 1: API キーを取得する

1. [Groqコンソール](https://console.groq.com/) を開いてログインし、必要な API キーまたは認証情報を作成します。
2. [API キー] ページで新しい API キーを作成します。
3. キーをコピーし、安全な場所に保管します。

::: warning API キーのセキュリティ
API キーをリポジトリに送信したり、スクリーンショットを含めたり、他の人に送信したりしないでください。キーが侵害されたら、すぐにそれを取り消し、Groq コンソールで新しいキーを作成します。
:::

## ステップ 2: AIRI で設定する

1. **[設定] → [プロバイダー] → [チャット] → [Groq]** を開きます。
2. API キーを基本設定に貼り付けます。
3. デフォルトのベース URL `https://api.groq.com/openai/v1` をそのまま使用します。

## ステップ 3: 構成を確認する

1. **検証**: 設定を保存し、プロバイダーページに表示される検証を実行します。その後、**設定 → モジュール → 意識**でプロバイダーとモデルを選択し、テストメッセージを送信します。
2. **モデルの選択**: テストが成功したら、ここをクリックして使用する特定のモデルを選択します。

## トラブルシューティング

API への ping が失敗した場合は、API キー、アカウント制限、ネットワーク接続を確認してください。モデル リストのロードに失敗した場合は、Groq が提供する正確なモデル ID を [意識] ページに手動で入力できます。
