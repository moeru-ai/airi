---
title: Azure OpenAI
description: AIRI で Azure OpenAI チャット モデルを構成する
---

Azure OpenAI は、Azure リソース エンドポイントとデプロイを通じてモデルにアクセスします。

::: info Azure OpenAI を選ぶ理由?
チームがすでに Azure OpenAI でモデルをデプロイし、アクセス許可を管理している場合、これはオンボードする簡単な方法です。
:::

## ステップ 1: Azure OpenAI リソースを準備する

1. [Azure Portal](https://portal.azure.com/) で Azure OpenAI リソースを作成し、使用するモデルをデプロイします。リソースの API キー、エンドポイント、デプロイ名、API バージョンを記録します。

::: warning API キーのセキュリティ
Azure API キーをリポジトリに送信したり、スクリーンショットを撮ったり、他の人に送信したりしないでください。
:::

## ステップ 2: AIRI で設定する

1. **[設定] → [プロバイダー] → [チャット] → [Azure OpenAI]** を開き、**API キー** と Azure OpenAI エンドポイントを入力します。
2. コンソールから提供される完全なチャット完了アドレスを入力することをお勧めします。アドレスにデプロイ名と `api-version` が含まれている場合、AIRI はそれに応じて設定を識別します。

## ステップ 3: 構成を確認する

1. API キー、エンドポイント、デプロイ情報を入力したら、プロバイダー設定を保存します。
2. **[設定] → [モジュール] → [意識]** に移動し、Azure OpenAI と対応するデプロイメントを選択して、メッセージを送信することで設定を確認します。

## トラブルシューティング

検証が失敗した場合は、API キー、エンドポイント、デプロイ名、`api-version` がすべて同じ Azure OpenAI リソースからのものであることを確認してください。プレゼンテーション専用のモデル名ではなく、デプロイメント名を使用してください。
