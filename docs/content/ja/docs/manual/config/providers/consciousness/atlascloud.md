Atlas Cloud は、OpenAI 形式に対応したチャット API プロバイダーです。このページでの設定を完了すると、AIRI は「意識」で Atlas Cloud が提供するチャット モデルを使用できるようになります。

::: info Atlas Cloud を選ぶ理由?
すでに Atlas Cloud API キーをお持ちの場合、または Atlas Cloud API キーが提供するモデルを使用したい場合は、このプロバイダーを直接選択できます。
:::

## ステップ 1: API キーを取得する

1. [Atlas Cloud](https://api.atlascloud.ai/) を開いてログインし、必要な API キーまたは認証情報を作成します。
2. キーをコピーし、安全な場所に保管します。

::: warning API キーのセキュリティ
API キーをリポジトリに送信したり、スクリーンショットを含めたり、他の人に送信したりしないでください。キーが侵害された場合は、直ちにそのキーを取り消し、Atlas Cloud コンソールで新しいキーを作成します。
:::

## ステップ 2: AIRI で設定する

1. **[設定] → [プロバイダー] → [チャット] → [Atlas Cloud]** を開きます。
2. API キーを基本設定に貼り付けます。
3. デフォルトのベース URL `https://api.atlascloud.ai/v1` をそのまま使用します。

## ステップ 3: 構成を確認する

1. **検証**: 設定を保存し、プロバイダーページに表示される検証を実行します。その後、**設定 → モジュール → 意識**でプロバイダーとモデルを選択し、テストメッセージを送信します。
2. **モデルの選択**: テストが成功したら、ここをクリックして使用する特定のモデルを選択します。

## トラブルシューティング

API への ping が失敗した場合は、API キー、アカウント制限、ネットワーク接続を確認してください。モデル リストの読み込みに失敗した場合は、Atlas Cloud から提供される正確なモデル ID を [意識] ページに手動で入力できます。
