---
title: BytePlus Coding Plan
description: AIRI での BytePlus コーディング プラン チャット モデルの設定
---

BytePlus コーディング プランは、AIRI で独立したプロバイダー カードとして利用できます。

::: info BytePlus コーディング プランを選択する理由?
BytePlus アカウントにコーディング プランがある場合は、対応するサービス プランに一致させるために、通常の BytePlus 構成の代わりにこのカードを使用する必要があります。
:::

## ステップ 1: BytePlus コーディング プランの認証情報を準備する

1. [BytePlus Console](https://console.byteplus.com/)を開き、Coding Plan の API キーを取得します。

::: warning API キーのセキュリティ
API キーやエンドポイント認証情報をリポジトリに送信したり、スクリーンショットを撮ったり、他の人に送信したりしないでください。
:::

## ステップ 2: AIRI で設定する

1. **設定 → プロバイダー → チャット → BytePlus Coding Plan**を開き、API キーを入力します。
2. Coding Plan のドキュメントで別の互換 API ルートが指定されない限り、デフォルトのベース URL を使用します。モデルは AIRI の静的一覧から選択します。このフォームにエンドポイントやモデルの入力欄はありません。

## ステップ 3: 構成を確認する

1. **検証**: 設定を保存し、プロバイダーページに表示される検証を実行します。その後、**設定 → モジュール → 意識**でプロバイダーとモデルを選択し、テストメッセージを送信します。
2. **モデルの選択**: テストが成功したら、**設定 → 意識**で利用可能なモデルを選択します。

## トラブルシューティング

検証に失敗した場合は、API キーが有効な BytePlus Coding Plan に属し、ベース URL が正しいことを確認します。一覧のモデルが拒否される場合は、プランのモデル利用権限を確認してください。
