---
title: BytePlus
description: AIRI での BytePlus チャット モデルの設定
---

BytePlus は、AIRI で Ark 互換のチャット サービス構成を使用します。

::: info BytePlusを選ぶ理由?
BytePlus アカウントで Ark API を利用できる場合に、このプロバイダーを使用します。
:::

## ステップ 1: BytePlus 認証情報を準備する

1. [BytePlus Console](https://console.byteplus.com/)を開き、Ark へアクセスできる API キーを作成します。

::: warning API キーのセキュリティ
API キーやエンドポイント認証情報をリポジトリに送信したり、スクリーンショットを撮ったり、他の人に送信したりしないでください。
:::

## ステップ 2: AIRI で設定する

1. **設定 → プロバイダー → チャット → BytePlus**を開き、API キーを入力します。
2. BytePlus のドキュメントで別の互換 API ルートが指定されない限り、デフォルトのベース URL を使用します。モデルは AIRI の一覧から選択します。このフォームに Endpoint ID やモデルの入力欄はありません。

## ステップ 3: 構成を確認する

1. **検証**: 設定を保存し、プロバイダーページに表示される検証を実行します。その後、**設定 → モジュール → 意識**でプロバイダーとモデルを選択し、テストメッセージを送信します。
2. **モデルの選択**: テストが成功したら、**設定 → 意識** に移動して、プロバイダーとモデルを選択します。

## トラブルシューティング

検証に失敗した場合は、API キー、ベース URL、アカウント権限、ネットワーク接続を確認します。モデルを利用できない場合は、プロバイダーが公開する一覧から別のモデルを選択してください。
