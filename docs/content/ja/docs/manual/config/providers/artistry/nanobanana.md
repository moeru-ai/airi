---
title: ナノバナナ（芸術作品）
description: AIRI での Nano Banana イメージ生成の設定
---

Nano Banana は、Google AI Studio API キーを使用して画像を生成します。設定が完了したら、**設定 → Artistry** でプロバイダーを選択できます。

::: info ナノバナナを選ぶ理由
すでに Google AI Studio API キーをお持ちで、AIRI の組み込み Gemini 画像モデルと解像度オプションを直接使用したい場合は、それを選択できます。
:::

## ステップ 1: API キーを取得する

1. [Google AI Studio API キー](https://aistudio.google.com/app/apikey) を開いてログインし、必要な API キーまたは認証情報を作成します。
2. 選択したイメージ モデルがアカウントと地域で利用できることを確認します。
3. キーをコピーし、安全な場所に保管します。

::: warning API キーのセキュリティ
API キーをリポジトリに送信したり、スクリーンショットを撮ったり、他の人に送信したりしないでください。キーが侵害された場合は、すぐにキーを取り消して、Google AI Studio で新しいキーを作成します。
:::

## ステップ 2: AIRI で設定する

1. **設定 → プロバイダー → Artistry → Nano Banana**を開き、API キーを貼り付けます。
2. デフォルトのモデル: `gemini-3.1-flash-image-preview`、`gemini-3-pro-image-preview`、または `gemini-2.5-flash-image` を選択します。
3. デフォルトの解像度を 1K、2K、または 4K から選択します。

## ステップ 3: 構成を確認する

1. **設定 → モジュール → Artistry**で **Nano Banana** を選択します。
2. **設定 → モジュール → 意識**で、ツール/関数呼び出しに対応するチャットモデルを選択します。
3. チャットに戻り、機密情報を含まない画像の生成を AIRI に依頼します。
4. 画像が返れば、API キー、モデル、解像度、ツール呼び出しを確認できます。

## トラブルシューティング

認証に失敗した場合は、API キーが有効か確認してください。画像生成に失敗した場合は、Google AI Studio アカウント、利用可能なリージョン、現在のモデルを確認し、1K 解像度または別のモデルで再試行します。
