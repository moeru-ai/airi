---
title: Replicate (Artistry)
description: AIRI で Replicate の画像生成を設定する
---

Replicate を使用すると、クラウド上のモデルで画像を生成できます。**設定 → プロバイダー → Artistry**で設定し、**設定 → モジュール → Artistry**で有効にします。

::: info Replicate を選択する理由
イメージ モデルを自分でデプロイするのではなく、Replicate で利用可能なモデルから選択したい場合は、クラウド推論サービスを選択できます。
:::

## ステップ 1: API トークンを取得する

1. [Replicate API Tokens](https://replicate.com/account/api-tokens)を開いてログインし、API トークンを作成します。
2. アカウントに利用可能な請求方法または制限が設定されていることを確認します。
3. トークンをコピーし、適切に保存します。

::: warning API トークンのセキュリティ
トークンをリポジトリに送信したり、スクリーンショットを撮ったり、他の人に送信したりしないでください。漏洩後は、すぐにトークンを取り消して、Replicate コンソールで新しいトークンを作成してください。
:::

## ステップ 2: AIRI で設定する

1. **設定 → プロバイダー → Artistry → Replicate**を開きます。
2. API トークンを貼り付けます。
3. デフォルトのモデル ID を入力します。AIRI のデフォルト値は `black-forest-labs/flux-schnell` です。Replicate のモデルページに表示される正確な ID を使用してください。
4. 必要に応じて、デフォルトの画面比率 (デフォルト `16:9`) と推論ステップ数 (デフォルト 4) を設定します。

## ステップ 3: 構成を確認する

1. **設定 → モジュール → Artistry**で **Replicate** を選択します。
2. **設定 → モジュール → 意識**で、ツール/関数呼び出しに対応するチャットモデルを選択します。
3. チャットに戻り、機密情報を含まない画像の生成を AIRI に依頼します。
4. 画像が返れば、トークン、モデル ID、アカウントクォータ、ツール呼び出しを確認できます。

## トラブルシューティング

認証に失敗した場合は、Tokenが完全に貼り付けられているか確認してください。リクエストが拒否または失敗した場合は、アカウント制限、モデルのアクセス権限、およびモデル ID を確認してください。生成された結果が期待を満たさない場合は、まずモデルがサポートするスケールとパラメーターの範囲を確認し、推論ステップ数を減らすか、モデルを置き換えます。
