---
title: チャットモデルの構成
description: AIRI のチャットプロバイダーとモデルの設定
---

チャットモデルはAIRIの「頭脳」です。このページを完了すると、AIRI はテキスト応答を生成できます。チャット機能をサポートするプロバイダー アカウント、または実行中のローカル モデル サービスが必要です。

## 前提条件

* AIRI がインストールされ、起動していること。
* クラウドプロバイダーでは、API キーを作成し、アカウントで対象のチャットモデルを利用できること。
* ローカル サービス: モデル サービスが開始されており、AIRI が配置されているデバイスはモデル サービスにアクセスできます。

## ステップ

1. **[設定] → [プロバイダー] → [チャット]** を開き、使用するプロバイダーを選択します。

どれを選択すればよいかわからない場合は、[OpenRouter](./providers/consciousness/openrouter.md)、[DeepSeek](./providers/consciousness/deepseek.md)、[OpenAI 互換 API](./providers/consciousness/openai.md)、ローカルの [Ollama](./providers/consciousness/ollama.md)から始められます。その他のチャットプロバイダーは**プロバイダー → チャット**にあります。

2. API キーを入力します。プロバイダーが専用の API アドレスを提供する場合は、詳細設定でベース URL を入力します。それ以外の場合は、デフォルト値をそのまま使用します。

3. プロバイダー設定を保存し、そのページに表示される検証内容を確認します。検証方法はプロバイダーごとに異なり、入力フィールドのみの確認、モデル一覧の取得、小さなリクエストの送信などがあります。

4. **設定 → モジュール → 意識**を開き、設定したプロバイダーとモデルを選択します。

プロバイダーがサポートしている場合、AIRI はモデル リストを読み込みます。リストをロードできない場合は、プロバイダーの公式ドキュメントに従って、正確なモデル ID を手動で入力できます。

5. チャット インターフェイスに戻り、「こんにちは」などの短いメッセージを送信します。応答を受信すると、構成が成功したことを示します。

## トラブルシューティング

### 検証は合格しましたが、オプションのモデルはありません

まず、プロバイダーがモデルのリストを許可していることを確認します。一部のプロバイダーはモデルリストを提供していないか、API キーに対応する権限がありません。この場合、「意識」ページでモデル ID を手動で入力できます。モデル ID はプロバイダーのドキュメントと正確に一致する必要があります。

### 検証が失敗したか、リクエストがタイムアウトしました

API キー、ベース URL、アカウント制限、ネットワーク接続を確認します。ローカル サービスの場合は、サービスが実行中であること、およびベース URL が他のデバイスのみがアクセスを許可されているアドレスではないことを確認します。

### AIRI から応答がない

「意識」ページでプロバイダーとモデルの両方が選択されていることを確認します。プロバイダーの資格情報を保存するだけでは、自動的に有効になりません。

## 次のステップ

チャット機能が正常になったら、[音声入力と出力の設定](./audio.md) に進み、AIRI に話させてマイクを入力に使用することができます。
