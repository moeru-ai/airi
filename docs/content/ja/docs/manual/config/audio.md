---
title: 音声入出力を構成する
description: 音声合成（TTS）および音声認識（ASR/STT）用の AIRI の設定
---

音声合成 (TTS) は AIRI のテキスト応答を読み上げます。音声認識 (ASR/STT) はマイクの音をテキストに変換します。この 2 つは独立して設定できます。TTS のみを設定すると AIRI の発話も許可され、ASR のみを設定すると音声入力も使用できるようになります。

## 音声合成 (TTS) を構成する

1. **設定 → プロバイダー → Speech**を開き、プロバイダーを選択して認証情報を入力します。
2. 利用できる場合はプロバイダーのプレイグラウンドで短い文章を合成し、再生できることを確認します。
3. **設定 → モジュール → 音声**を開き、設定したプロバイダー、モデル、Voice を選択します。

プロバイダーが OpenAI 音声インターフェイスと互換性がある場合は、[OpenAI 互換 API (TTS)](./providers/speech/openai.md) を参照してください。 OpenRouter の音声インターフェースを使用する場合は、[OpenRouter (TTS)](./providers/speech/openrouter.md) を参照してください。

## 音声認識 (ASR/STT) を構成する

1. **設定 → プロバイダー → Transcription**を開き、プロバイダーを選択して認証情報を入力します。
2. **設定 → モジュール → 聴覚**を開き、設定したプロバイダーとモデルを選択します。
3. 正しいマイクを選択し、テストを開始して短い文を発話します。
4. 認識結果領域にテキストが正しく表示されることを確認します。

Alibaba Cloud のリアルタイム文字起こしについては、[Alibaba Cloud NLS](./providers/transcription/aliyun.md)を参照してください。OpenAI 文字起こし API と互換性のあるサービスについては、[OpenAI 互換 API (ASR/STT)](./providers/transcription/openai.md)を参照してください。

## よくある質問

### TTS 音が出ない

Speech プロバイダー、モデル、Voice が選択されていることを確認し、システムの出力デバイスと音量を確認します。プレイグラウンドにエラーが表示される場合は、API キー、残高、モデルの対応機能を確認してください。

### ASR テキスト結果がありません

AIRI がマイクに対する許可を持っていること、および聴覚 ページで正しい入力デバイスが選択されていることを確認します。リアルタイム認識サービスの場合、ネットワークの停止やブラウザ/システムのマイク許可が取り消されると、結果が空になる可能性があります。

### 言語または Voice が正しくない

対象言語に対応するモデルと Voice を選択します。文字起こしの言語、リージョン、モデル設定は、プロバイダーアカウントで有効な機能と一致させてください。
