## AIRI へようこそ!

初めて AIRI を開いたら、**プロバイダーでセットアップ**を選択します。AIRI 公式プロバイダーを使用する場合は、**サインイン**を選択します。

### Chat プロバイダーの選択

OpenAI、DeepSeek、Ollama などの Chat プロバイダーを選択します。OpenAI API と互換性のある別サービスを使用する場合は、**OpenAI 互換 API**を選択し、そのサービスの API キーとドキュメントに記載されたベース URL を入力します。画像では SiliconFlow を例にしています。

![AIRI のプロバイダー API 設定例](/assets/screenshot-api-example.avif)

### モデルを選択してください

互換性のあるチャットモデルを選択し、**始めましょう！**を選択します。

::: tip

think 関数を備えたモデルを使用している場合、応答の生成に時間がかかることがあります。会話の流暢さを向上させるには、非思考モデルを使用することをお勧めします。

:::

### 最初の会話を始めます

チャットボックスにテキストを入力して AIRI に送信します。
![AIRI Web のチャット画面](/assets/screenshot-chat.avif)

## 目、耳、口

テキスト対話に加えて、AIRI は音声、聴覚、Vision などのモジュールを利用できます。右上の**設定 → モジュール**から構成します。

### AIRIに話してもらいましょう

**設定 → プロバイダー → Speech**で音声プロバイダーを設定します。その後、**設定 → モジュール → 音声**でプロバイダー、モデル、Voice を選択します。

### AIRIに音を聞かせてください

**設定 → プロバイダー → Transcription**で文字起こしプロバイダーを設定します。その後、**設定 → モジュール → 聴覚**でプロバイダーとモデルを選択し、使用するマイクを指定します。メインページのマイクボタンから聴覚コントロールを開けます。

### AIRIに会いましょう

Vision は現在も実験的な機能です。対応しているデスクトップキャプチャとプロバイダー設定については、[Vision の設定](../config/vision.md)を参照してください。


## キャラクターカード

AIRIには「ReLU」というキャラクターカードが内蔵されており、モデルに自分でキャラクターカードを書くこともできます。ホームページ右上にキャラクターカード切り替えボタンがあるか、設定からも切り替えられます。

### キャラクターカードの内容

キャラクターカードにはAIRIの名前、説明、性格、行動などが含まれており、AIを高度にカスタマイズできます。

### キャラクターカードの設定

キャラクターカードにはモジュール設定を保存できます。プロファイルを切り替えると、キャラクターと関連するモデル設定をまとめて切り替えられます。
