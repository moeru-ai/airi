## AIRI에 오신 것을 환영합니다!

AIRI를 처음 열면, 필요하다면 오른쪽 위의 지구본 버튼으로 인터페이스 언어를 변경하세요. 그런 다음 **직접 제공자 설정하기**를 선택하거나, 공식 AIRI 제공자를 사용하려면 **로그인**을 선택하세요.

### 채팅 제공자 선택

OpenAI, DeepSeek, Ollama 같은 채팅 제공자를 선택하세요. OpenAI API를 구현한 다른 서비스를 사용하려면 **OpenAI Compatible**을 선택하고 해당 서비스의 API Key와 문서에 안내된 Base URL을 모두 입력하세요. 스크린샷은 SiliconFlow를 예시로 사용합니다.

![AIRI 제공자 API 설정 예시](/assets/screenshot-api-example.avif)

### 모델 선택

호환되는 채팅 모델을 선택한 뒤 **저장하고 계속하기**를 선택하세요.

::: tip

추론 모델은 응답에 시간이 더 걸릴 수 있습니다. 더 빠른 대화를 원한다면 비추론 모델을 선택하세요.

:::

### 첫 대화 시작하기

채팅 상자에 텍스트를 입력해 AIRI에게 보내세요.
![AIRI 웹 채팅 인터페이스](/assets/screenshot-chat.avif)

## 눈, 귀, 그리고 입

AIRI는 텍스트 대화 외에도 다양한 상호작용 방식을 지원합니다. 오른쪽 위의 **설정 → 모듈**을 열어 더 많은 기능을 설정하세요.

### AIRI가 말하게 하기

**설정 → 제공자 → 음성 합성**을 열어 음성 합성 제공자를 설정하세요. 그런 다음 **설정 → 모듈 → 음성 합성**을 열어 제공자, 모델, 목소리를 선택하세요.

### 음성 입력 활성화

**설정 → 제공자 → 전사**를 열어 전사 제공자를 설정하세요. 그런 다음 **설정 → 모듈 → 청각**을 열어 제공자와 모델을 선택하고 사용 가능한 마이크를 고르세요. 메인 페이지의 마이크 버튼으로 청각 컨트롤을 열 수 있습니다.

### 비전 캡처는 현재 데스크톱 전용

화면·창 캡처는 현재 데스크톱 버전에서 사용할 수 있습니다. 제공자 설정과 데스크톱 Vision Capture 워크플로는 [비전 설정](../config/vision.md)을 참고하세요.

## 캐릭터 카드

AIRI에는 "ReLU"라는 캐릭터 카드가 기본으로 포함되어 있으며, 직접 캐릭터 카드를 만들 수도 있습니다. 메인 페이지 오른쪽 위의 캐릭터 전환 버튼을 사용하거나 설정에서 카드를 전환하세요.

### 캐릭터 카드 내용

캐릭터 카드는 AIRI의 이름, 설명, 성격, 시나리오, 인사말을 정의합니다. 캐릭터 카드로 AIRI의 정체성과 행동을 원하는 대로 바꿀 수 있습니다.

### 캐릭터 카드 설정

캐릭터 카드에는 모듈 설정을 저장할 수 있습니다. 따라서 프로필을 전환하면 캐릭터와 그에 연결된 모델 선택이 함께 바뀝니다.
