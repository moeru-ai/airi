302.AI는 API 통합 제공자입니다. 설정을 완료한 후 **설정 → 모듈 → 의식**에서 302.AI 채팅 모델을 선택하세요.

::: info 왜 302.AI를 선택하나요?
중국 본토에서 AIRI를 주로 사용한다면 302.AI를 먼저 시도해 볼 수 있습니다. 통합 API를 제공하므로 하나의 API Key로 여러 모델을 쉽게 사용해 볼 수 있습니다. 다만 실제 사용 가능 여부는 네트워크 환경, 결제 수단, 서비스 제공자 정책에 따라 달라질 수 있습니다.
:::

## API Key 발급받기

1. [302.AI 콘솔](https://302.ai/)을 열고 로그인하거나 계정을 만드세요.
2. 콘솔에서 API Key를 생성하세요.
3. 키를 복사해 안전한 곳에 보관하세요.

::: warning API Key 보안
API Key를 커밋하거나, 스크린샷에 포함하거나, 누구와도 공유하지 마세요. 키가 유출되면 즉시 폐기하고 302.AI 콘솔에서 새 키를 만드세요.
:::

## AIRI에서 설정하기

1. **설정 → 제공자 → 채팅 → 302.AI**를 여세요.
2. 기본 설정에 API Key를 붙여넣으세요.
3. 기본 Base URL을 그대로 유지하세요: `https://api.302.ai/v1/`.

## 설정 확인

1. **설정 유효성 검사**: AIRI는 설정을 수정하는 동안 자동으로 유효성을 검사합니다. **Ping API** 버튼이 보이면 실제 요청 테스트에 사용할 수 있습니다.
2. **모델 선택 →**: 유효성 검사가 통과되면 이 버튼으로 **설정 → 모듈 → 의식**을 열어 제공자와 모델을 선택하세요.

## 문제 해결

API 확인이 실패하면 API Key, 계정 잔액, 네트워크 연결을 점검하세요. AIRI가 모델 목록을 불러오지 못하면 **의식** 페이지에서 302.AI가 제공하는 정확한 모델 ID를 직접 입력하세요.
