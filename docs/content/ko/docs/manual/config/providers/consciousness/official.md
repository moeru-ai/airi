---
title: AIRI 공식 제공자
description: AIRI 공식 채팅 제공자 사용하기
---

AIRI를 빠르게 시작하고 설정을 간단히 하고 싶다면 공식 제공자로 채팅을 활성화할 수 있습니다.

::: info 왜 AIRI 공식 제공자를 선택하나요?
서드파티 API Key를 직접 설정하지 않고 AIRI를 빠르게 체험하고 싶다면 공식 제공자를 선택할 수 있습니다.
:::

## 계정에 로그인하기

1. 로그인 버튼을 클릭하면 브라우저 페이지가 열립니다.
2. 로그인 방법을 선택하세요. 현재 이메일, Google, GitHub 로그인을 지원합니다.

    ::: info 중국 사용자를 위한 특별 안내
    중국에 있는 사용자는 Google과 GitHub로 로그인하지 못할 수 있습니다. 이메일로 로그인해 주세요. 휴대폰 번호를 이용한 가입과 로그인은 현재 지원하지 않습니다.
    :::

3. 안내에 따라 로그인/가입을 완료하세요.

    ::: info
    이메일이 도착하지 않으면 스팸함을 확인하세요.
    :::

## 사용 가능한 Flux 확인

Flux는 AIRI 공식 서비스에서 사용하는 잔액입니다. 초기 지급량은 현재 배포 환경의 설정에 따라 다르므로, 고정된 금액을 가정하지 말고 **설정 → Flux**에 표시된 잔액을 확인하세요.

## 제공자 활성화

1. **설정 → 모듈 → 의식**을 여세요.
2. **Official Provider**와 **Auto** 모델을 선택하세요.
3. 짧은 메시지를 보내 AIRI가 응답하는지 확인하세요.

AIRI는 활성화된 채팅 제공자가 없을 때만 공식 제공자를 자동으로 선택합니다. 이전에 다른 제공자를 선택했다면 로그인해도 그 선택이 바뀌지 않습니다.

## Flux 충전

**설정 → Flux**를 열고 사용 가능한 패키지를 선택하세요. 데스크톱에서는 AIRI가 시스템 브라우저에서 결제 페이지를 열고, 앱이 다시 포커스를 얻으면 잔액을 갱신합니다. 구매가 비활성화된 빌드나 배포 환경에서는 결제를 제공하지 않습니다.

## 문제 해결

로그인 이메일을 받지 못하면 스팸함을 확인하세요. Flux 패키지가 보이지 않거나 결제를 생성할 수 없다면 해당 배포 환경에서 구매가 비활성화되었거나 일시적으로 사용할 수 없는 상태일 수 있습니다.
