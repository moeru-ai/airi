n1n은 AIRI에서 API 호환 채팅 모델 접근을 제공합니다.

::: info 왜 n1n을 선택하나요?
n1n의 모델 서비스를 사용한다면 AIRI에 서비스 주소와 계정 자격 증명을 입력해 사용할 수 있습니다.
:::

## 서비스 접근 방법 준비하기

1. [n1n](https://n1n.ai/)에 로그인한 뒤, 서비스 URL과 API Key 필요 여부를 확인하세요.

::: warning 자격 증명 보안
API Key가 선택 사항이더라도 개인 서비스 주소, 액세스 토큰, 게이트웨이 설정을 노출하지 마세요.
:::

## AIRI에서 설정하기

1. **설정 → 제공자 → 채팅 → n1n**을 여세요. 기본 Base URL은 `https://api.n1n.ai/v1/`입니다.
2. n1n의 현재 서비스 요구 사항에 따라 API Key를 입력하세요. 배포 환경이 익명 접근을 허용한다면 배포자의 안내에 따라 비워 두세요.

## 설정 확인

1. **설정 유효성 검사**: AIRI는 설정을 수정하는 동안 자동으로 유효성을 검사합니다. **Ping API** 버튼이 보이면 실제 요청 테스트에 사용할 수 있습니다.
2. **모델 선택 →**: 유효성 검사가 통과되면 이 버튼으로 **설정 → 모듈 → 의식**을 열어 제공자와 모델을 선택하세요.

## 문제 해결

확인이 실패하면 서비스 주소, API Key, 배포자의 접근 정책을 점검하세요. 서비스가 익명 접근을 허용한다면 배포자의 안내에 따라 API Key를 비워 두고, AIRI를 실행하는 기기에서 해당 주소에 접근할 수 있는지 확인하세요.
