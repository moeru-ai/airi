xAI 제공자를 사용하면 AIRI가 Grok 채팅 모델을 사용할 수 있습니다. 설정 방법은 일반적인 API Key 서비스 제공자와 동일합니다.

::: info 왜 xAI를 선택하나요?
이미 xAI API 계정이 있고 AIRI에서 Grok 모델을 사용하고 싶다면 이 서비스 제공자를 선택할 수 있습니다.
:::

## API Key 생성하기

1. [xAI Developer Console](https://console.x.ai/)에 로그인한 뒤 API Key를 만드세요.
2. 계정이 API 사용을 위해 활성화되어 있고 사용 가능한 할당량이 있는지 확인하세요.
3. 키를 복사하세요.

::: warning API Key 보안
API Key는 비밀번호 관리자나 AIRI의 로컬 설정에만 저장하세요. 키를 코드에 적거나, 저장소에 커밋하거나, 다른 사람에게 보내지 마세요.
:::

## AIRI에서 설정하기

1. **설정 → 제공자 → 채팅 → xAI**를 여세요.
2. API Key를 입력하세요.
3. 기본 Base URL을 그대로 유지하세요: `https://api.x.ai/v1/`.

## 설정 확인

1. **설정 유효성 검사**: AIRI는 설정을 수정하는 동안 자동으로 유효성을 검사합니다. **Ping API** 버튼이 보이면 실제 요청 테스트에 사용할 수 있습니다.
2. **모델 선택 →**: 유효성 검사가 통과되면 이 버튼으로 **설정 → 모듈 → 의식**을 열어 제공자와 모델을 선택하세요.

## 문제 해결

제공자 유효성 검사가 실패하면 API Key, 사용 가능한 크레딧 또는 할당량, 요청 한도, 네트워크 연결을 확인하세요. AIRI가 모델 목록을 불러오지 못하면 **의식** 페이지에서 xAI 문서에 있는 정확한 모델 ID를 직접 입력하세요.
