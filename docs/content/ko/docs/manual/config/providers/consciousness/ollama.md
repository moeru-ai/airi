---
title: Ollama (로컬 모델)
description: 로컬 Ollama 서비스로 AIRI 채팅 모델 설정하기
---

Ollama는 언어 모델을 로컬에서 실행하는 오픈소스 런타임입니다. 로컬 API를 제공하며 기본적으로 API Key가 필요하지 않습니다.

::: info 왜 Ollama를 선택하나요?
모델을 직접 실행하고 싶거나, 클라우드 API 의존도를 줄이고 싶거나, 대화 데이터의 로컬 처리를 더 중시한다면 Ollama가 알맞은 선택입니다.
:::

## Ollama 설치하기

1. [공식 웹사이트](https://ollama.com/)에서 운영 체제에 맞는 Ollama를 다운로드해 설치하세요.
2. Terminal이나 PowerShell에서 다음 명령어를 실행해 설치를 확인하세요:

    ```bash
    ollama --version
    ```

## 모델 다운로드 및 실행

1. 다음 명령어를 실행해 모델을 다운로드하고 시작하세요:

    ```bash
    ollama run qwen2
    ```

2. 다른 모델을 사용하려면 `qwen2`를 해당 모델 ID로 바꾸세요. 최초 다운로드 시간은 모델 크기와 네트워크 속도에 따라 다릅니다.

## AIRI에서 설정하기

1. **설정 → 제공자 → 채팅 → Ollama**를 여세요.
2. 기본 Base URL인 `http://localhost:11434/v1/`를 유지하세요. Ollama가 다른 기기에서 실행 중이라면 AIRI를 실행하는 기기에서 접근할 수 있는 URL을 입력하세요.
3. **설정 → 모듈 → 의식**에서 Ollama와 다운로드한 모델을 선택하세요.

## 설정 확인

1. **설정 유효성 검사**: AIRI는 설정을 수정하는 동안 자동으로 유효성을 검사합니다. **Ping API** 버튼이 보이면 실제 요청 테스트에 사용할 수 있습니다.
2. **모델 선택 →**: 유효성 검사가 통과되면 이 버튼으로 **설정 → 모듈 → 의식**을 열어 다운로드한 모델을 선택하세요.

## 문제 해결

AIRI가 연결하지 못하면 Ollama가 실행 중인지, Base URL이 올바른 포트를 사용하는지 확인하세요. AIRI와 Ollama가 서로 다른 기기에서 실행 중이라면 AIRI 기기에서 접근할 수 있는 LAN 주소를 사용하고, 신뢰할 수 있는 네트워크에서만 서비스를 노출하세요.

::: warning AIRI가 로컬 Ollama에 연결하지 못할 때
Ollama가 실행 중인데도 AIRI가 CORS 오류를 보고하면, `OLLAMA_ORIGINS`에 AIRI의 정확한 origin을 추가하고 Ollama를 재시작하세요. 문제 해결의 지름길이라는 이유로 와일드카드를 사용하거나 Ollama를 공용 인터넷에 노출하지 마세요.
:::
