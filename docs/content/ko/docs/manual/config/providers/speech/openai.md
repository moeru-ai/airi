title: OpenAI 호환 API (TTS)
description: AIRI에서 OpenAI 또는 OpenAI 호환 API를 음성 합성 제공자로 설정하기
---

이 페이지에서는 OpenAI 음성 API를 구현하는 제공자를 설정합니다. 제공자를 저장한 다음 **설정 → 모듈 → 음성 합성**에서 해당 모델과 음성을 선택하세요.

::: info 왜 TTS에 OpenAI 호환 API를 사용하나요?
사용 중인 음성 서비스가 OpenAI 음성 API를 명시적으로 지원할 때 이 제공자를 사용하세요. API 주소가 `/v1`로 끝나거나 키가 `sk-`로 시작한다고 해서 호환성이 보장되는 것은 아닙니다.
:::

## API Key 발급받기

1. 선택한 서비스 제공자의 관리 콘솔에 로그인하세요.
2. API Key 또는 개발자 설정 페이지에서 API Key를 생성하세요.
3. 키를 복사해 안전한 곳에 보관하세요.

::: warning API Key 보안
API Key를 커밋하거나, 스크린샷에 포함하거나, 누구와도 공유하지 마세요. 키가 유출되면 즉시 폐기하고 제공자 콘솔에서 새 키를 만드세요.
:::

## AIRI에서 설정하기

1. **설정 → 제공자 → 음성 합성 → OpenAI Compatible**을 여세요.
2. API Key와 사용할 TTS 모델 ID를 입력하세요.
3. 공식 OpenAI를 사용하려면 별도의 **OpenAI** 제공자를 선택하세요. **OpenAI Compatible** 제공자에는 기본 Base URL이 없으므로, 호환 서비스 문서에 안내된 전체 API 루트를 입력하세요.
4. 필요에 따라 말하기 속도를 조정하세요.

## 설정 확인

1. **설정 → 모듈 → 음성 합성**에서 설정한 제공자, 모델, 음성을 선택하세요.
2. 테스트 텍스트를 입력하고 **Test Voice**를 클릭하세요.
3. 테스트 오디오가 재생되면 제공자가 올바르게 설정된 것입니다. AIRI에 오류가 표시되면 오류 메시지를 참고해 자격 증명, 모델 ID, Base URL을 확인하세요.

## 문제 해결

오디오가 재생되지 않으면 선택한 모델과 음성을 제공자가 지원하는지 확인하세요. 호환 서비스라면 해당 서비스가 OpenAI 음성 API를 구현하는지 확인하세요.
