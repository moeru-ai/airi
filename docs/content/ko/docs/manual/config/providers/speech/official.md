---
title: 공식 음성 합성 제공자 (TTS)
description: AIRI에서 공식 제공 음성 합성 사용하기
---

공식 음성 합성은 활성화된 AIRI 세션을 사용하며, 서드파티 API Key가 필요하지 않습니다.

::: info 왜 AIRI 공식 음성 합성을 선택하나요?
이미 공식 AIRI 제공자를 사용하고 있고 서드파티 자격 증명 설정을 줄이고 싶다면 이 옵션을 먼저 사용해 보세요.
:::

## 계정에 로그인하기

1. AIRI 계정으로 로그인하세요.
2. 현재 세션에서 공식 음성 합성 제공자를 사용할 수 있는지 확인하세요.

::: warning 계정 및 서비스 가용성
사용 가능한 모델, 할당량, 지역은 공식 서비스에 따라 결정됩니다. 계정 세션이나 브라우저 세션 데이터를 공유하지 마세요.
:::

## AIRI에서 설정하기

1. **설정 → 제공자 → 음성 합성 → Official Speech Provider**를 여세요.
2. 로그인하라는 안내가 표시되면 로그인하세요. 페이지에 Flux 잔액과 정상 연결 상태가 표시되는지 확인하세요.

## 설정 확인

1. **설정 → 모듈 → 음성 합성**을 열고 **Official Speech Provider**를 선택한 다음 사용 가능한 모델과 음성을 선택하세요.
2. 짧은 테스트 문장을 입력하고 **Test Voice**를 클릭한 다음 AIRI가 생성된 오디오를 재생하는지 확인하세요.

## 스트리밍 제공자 (선택 사항)

공식 서비스에서 스트리밍 TTS를 사용할 수 있다고 알리면, AIRI는 **설정 → 제공자 → 음성 합성** 아래에 별도의 **Official Streaming Speech Provider** 카드를 표시합니다.

**설정 → 모듈 → 음성 합성**에서는 **Official Speech Provider**를 그대로 선택해 두세요. AIRI는 해당 제공자의 모델 목록에 스트리밍 모델을 포함합니다. 스트리밍 모델과 음성을 선택하면 AIRI가 선택된 모델에 맞춰 내부 음성 합성 제공자를 자동으로 전환합니다.

## 문제 해결

제공자를 사용할 수 없으면 로그인되어 있는지, AIRI가 공식 서비스에 접근할 수 있는지 확인하세요. 계정에 Flux가 충분한지도 확인하세요. **설정 → Flux**를 열면 사용 가능한 패키지를 볼 수 있습니다. 데스크톱 버전은 시스템 브라우저에서 결제 페이지를 엽니다. 빌드나 배포 환경이 구매를 지원하지 않으면 구매 옵션이 표시되지 않습니다.
