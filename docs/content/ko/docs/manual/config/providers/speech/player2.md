title: Player2 (TTS)

---

Player2 Speech는 로컬 서비스를 통해 연결하는 음성 합성 옵션입니다.

::: info 왜 Player2를 선택하나요?
이미 Player2 Speech를 로컬 또는 신뢰할 수 있는 LAN에서 실행하고 있다면, AIRI를 해당 서비스에 연결해 사용 가능한 음성을 이용할 수 있습니다.
:::

## 로컬 서비스 시작하기

1. Player2 Speech 서비스를 시작하고 헬스 체크가 가능한지 확인하세요.
2. AIRI는 기본적으로 `http://localhost:4315/v1/`에 연결합니다. 서비스가 다른 주소에서 실행 중이라면 전체 Base URL을 기록해 두세요.

::: warning 로컬 서비스 보안
로컬 서비스 포트를 신뢰할 수 없는 공용 네트워크에 노출하지 마세요.
:::

## AIRI에서 설정하기

1. **설정 → 제공자 → 음성 합성 → Player2**를 여세요.
2. 서비스의 Base URL을 입력하세요.

## 설정 확인

1. 제공자 플레이그라운드에서 사용 가능한 음성을 선택하세요. 이 페이지는 AIRI의 기본 Player2 모델을 사용합니다.
2. 같은 페이지의 플레이그라운드에 짧은 텍스트를 입력하고 오디오가 재생되는지 확인하세요.

## AIRI 응답에 사용하기

**설정 → 모듈 → 음성 합성**을 열고 **Player2**를 선택한 다음 사용 가능한 모델과 음성을 선택하세요. 플레이그라운드 테스트만으로는 일반 응답에 제공자가 활성화되지 않습니다.

## 문제 해결

연결이 실패하면 서비스의 `/health` 응답과 Base URL을 확인하세요. 음성 목록이 비어 있으면 서비스의 `/tts/voices` 인터페이스에 접근할 수 있는지 확인하세요.
