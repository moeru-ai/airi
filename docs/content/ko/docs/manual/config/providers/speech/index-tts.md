---
title: Index-TTS (로컬 TTS)
description: AIRI에서 로컬 Index-TTS 서비스에 연결하기
---

Index-TTS는 로컬 HTTP 서비스를 통해 AIRI에 연결됩니다.

::: info 왜 Index-TTS를 선택하나요?
Index-TTS를 이미 로컬에서 실행 중이고 소리 데이터를 로컬 네트워크 안에 유지하고 싶다면 이 옵션을 선택할 수 있습니다.
:::

## 로컬 서비스 시작하기

1. Index-TTS의 배포 안내에 따라 서비스를 시작하세요.
2. AIRI는 기본적으로 `http://localhost:11996/tts/`에 연결합니다. 다른 호스트나 포트를 사용한다면 전체 주소를 기록해 두세요.
3. 서비스가 모델과 음성 정보를 반환할 수 있는지 확인하세요.

::: warning 로컬 서비스 보안
로컬 서비스 포트를 신뢰할 수 없는 공용 네트워크에 노출하지 마세요. 수신 대기 주소를 변경했다면 서비스 접근을 직접 보호하세요.
:::

## AIRI에서 설정하기

1. **설정 → 제공자 → 음성 합성 → Bilibili / IndexTTS**를 여세요.
2. 로컬 서비스의 Base URL을 입력하세요.

## 설정 확인

1. 제공자 플레이그라운드에서 사용 가능한 음성을 선택하세요. 이 페이지는 설정한 Index-TTS 서비스와 AIRI의 기본 모델 ID를 사용합니다.
2. 같은 페이지의 플레이그라운드에 짧은 텍스트를 입력하고 오디오가 재생되는지 확인하세요.

## AIRI 응답에 사용하기

**설정 → 모듈 → 음성 합성**을 열고 **Bilibili / IndexTTS**를 선택한 다음 모델 ID `IndexTTS-1.5`와 음성을 선택하세요. 제공자 테스트만으로는 일반 응답에 음성이 활성화되지 않습니다.

## 문제 해결

연결할 수 없으면 서비스가 실행 중인지, Base URL에 올바른 포트가 포함되어 있는지 확인하고 로컬 방화벽이나 리버스 프록시를 점검하세요. 음성 목록이 비어 있으면 서비스의 `audio/voices` 인터페이스가 사용 가능한지 확인하세요.
