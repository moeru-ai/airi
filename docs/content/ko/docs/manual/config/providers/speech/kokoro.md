---

Kokoro는 AIRI 안에서 네이티브 모델로 음성 합성을 실행합니다.

::: info 왜 Kokoro를 선택하나요?
음성을 로컬에서 합성하고 싶고 기기에 모델을 실행할 자원이 충분하다면 Kokoro를 선택하세요.
:::

## 로컬 실행 환경 준비하기

1. AIRI를 열고 첫 사용 시 모델 다운로드가 완료될 때까지 기다리세요.
2. WebGPU를 사용할 수 있으면 합성이 가속됩니다. WebGPU가 없어도 AIRI는 WASM으로 대체 동작할 수 있지만, 일반적으로 합성이 느려지고 CPU를 더 많이 사용합니다.
3. 이 옵션은 클라우드 API Key가 필요 없지만 로컬 저장 공간, 메모리, 연산 자원을 사용합니다.

::: warning 로컬 자원 사용
모델은 로컬 저장 공간, 메모리, CPU 또는 GPU 자원을 사용합니다. 다운로드가 완료되지 않거나, 메모리 압박이 크거나, 합성 때문에 기기가 응답하지 않으면 호스팅형 음성 제공자를 대신 사용하세요.
:::

## AIRI에서 설정하기

1. **설정 → 제공자 → 음성 합성 → Kokoro TTS (Local)**를 여세요.
2. AIRI가 제공하는 사용 가능한 Kokoro 모델을 선택하세요.

## 설정 확인

1. **모델과 음성 선택**: 모델이 준비되면 음성을 선택한 다음 **설정 → 모듈 → 음성 합성**으로 이동해 활성화하세요.
2. 짧은 테스트 문장을 입력하고 AIRI가 생성된 오디오를 재생하는지 확인하세요.

## 문제 해결

모델을 로드할 수 없으면 사용 가능한 저장 공간과 메모리를 확인한 다음 페이지를 다시 열어 다운로드가 끝날 때까지 기다리세요. WebGPU를 사용할 수 없으면 WASM 대체 동작이 초기화와 합성을 마칠 때까지 시간을 더 주세요.
