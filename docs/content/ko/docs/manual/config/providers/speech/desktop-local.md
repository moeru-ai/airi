description: 데스크톱 로컬 음성 합성은 아직 설정할 수 없습니다
---

앱(로컬) 음성 합성은 아직 사용할 수 없습니다. 해당 AIRI 설정 페이지는 현재 Work in Progress 자리 표시자만 보여 주므로, 모델과 음성을 준비하거나 선택할 수 없습니다.

::: warning 사용 불가
아직 실제 동작하는 설정에 이 제공자를 사용하지 마세요. 현재 사용 가능 여부를 명확히 하기 위해서만 문서화되어 있습니다.
:::

## 사용 가능한 대안

AIRI에 구현된 로컬 음성 합성이 필요하면 [Kokoro](./kokoro.md)를 사용하거나, 지원되는 클라우드 TTS 제공자를 선택하세요.
