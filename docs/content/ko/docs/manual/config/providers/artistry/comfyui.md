---
title: ComfyUI (Artistry)
description: 로컬 ComfyUI 워크플로를 AIRI에 연결하기
---

ComfyUI를 사용하면 AIRI가 로컬 머신이나 신뢰할 수 있는 LAN의 이미지 생성 워크플로를 사용할 수 있습니다. 제공자 페이지에서 워크플로를 설정하고 활성화한 뒤, **설정 → 모듈 → Artistry**에서 **ComfyUI (Local)**을 선택하세요.

::: info 왜 ComfyUI를 선택하나요?
이미지 생성을 로컬 환경에서 유지하면서 직접 설치한 모델·노드·워크플로를 사용하려면 ComfyUI를 선택하세요.
:::

## ComfyUI 서비스와 워크플로 준비하기

1. ComfyUI를 시작하세요. AIRI는 기본적으로 `http://localhost:8188`에 연결합니다.
2. ComfyUI에서 직접 실행할 수 있는 이미지 워크플로를 준비하고, ComfyUI에서 해당 워크플로의 API 워크플로 JSON을 내보내세요.
3. AIRI와 ComfyUI가 같은 기기에 있지 않다면, AIRI가 있는 기기에서 해당 주소에 접근할 수 있는지 확인하세요.

::: warning 로컬 서비스와 워크플로 보안
ComfyUI의 서비스 포트를 신뢰할 수 없는 공용 네트워크에 노출하지 마세요. 워크플로를 가져오기 전에 워크플로의 노드, 모델 경로, 매개변수를 확인하고, 출처를 알 수 없는 워크플로 JSON은 가져오지 마세요.
:::

## AIRI에서 설정하기

1. **설정 → 제공자 → Artistry → ComfyUI**를 여세요.
2. ComfyUI **Server URL**을 입력하세요. 기본값은 `http://localhost:8188`입니다.
3. **Test**를 클릭해 AIRI가 ComfyUI 서비스 상태를 읽을 수 있는지 확인하세요.
4. Workflow 영역에 API 워크플로 JSON을 업로드하고, 이름을 입력한 뒤, AIRI가 제어할 수 있는 입력 필드를 선택하세요.
5. 워크플로를 저장하고 활성 워크플로로 지정하세요.

## 설정 확인

1. **설정 → 모듈 → 의식**에서 도구 호출을 지원하는 채팅 모델을 선택하세요. ComfyUI가 생성 작업을 받으려면 먼저 모델이 Artistry 도구를 호출해야 합니다.
2. **설정 → 모듈 → Artistry**를 열고 **ComfyUI (Local)**을 선택하세요.
3. 채팅으로 돌아가 AIRI에게 민감하지 않은 이미지를 생성해 달라고 요청하세요.
4. ComfyUI의 Queue 또는 History에 작업이 나타나는지 확인하세요. 이미지가 반환되면 연결, 활성 워크플로, 노출된 필드, 채팅 모델의 도구 호출이 모두 정상 동작하는 것입니다.

## 문제 해결

- **Test가 실패하는 경우:** ComfyUI가 실행 중인지, 그리고 **Server URL**, 포트, 네트워크 경로가 올바른지 확인하세요.
- **브라우저에 교차 출처(cross-origin) 오류가 표시되는 경우:** AIRI의 ComfyUI 제공자 페이지에 표시된 CORS 옵션으로 ComfyUI를 다시 시작하세요.
- **워크플로가 ComfyUI에서 실패하는 경우:** API 형식의 워크플로 JSON을 가져온 뒤, 참조된 모든 커스텀 노드와 모델이 설치되어 있는지 확인하세요.
- **Queue나 History에 작업이 나타나지 않는 경우:** 대화형 Artistry 흐름에서는 선택한 채팅 모델이 도구 호출을 지원하는지, 그리고 **설정 → 모듈 → Artistry**가 **ComfyUI (Local)**로 설정되어 있는지 확인하세요. 도구를 호출할 수 없는 텍스트 전용 모델은 대화형 Artistry 작업을 시작할 수 없습니다.
