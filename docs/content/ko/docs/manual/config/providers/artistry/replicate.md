Replicate를 사용하면 AIRI가 클라우드에 호스팅된 모델로 이미지를 생성할 수 있습니다. **설정 → 제공자 → Artistry**에서 설정한 뒤, **설정 → 모듈 → Artistry**에서 활성화하세요.

::: info 왜 Replicate를 선택하나요?
이미지 모델을 직접 배포하고 싶지 않고 Replicate에서 제공하는 모델 중에서 선택하고 싶다면 이 클라우드 추론 서비스를 선택할 수 있습니다.
:::

## API Token 발급받기

1. [Replicate API Tokens](https://replicate.com/account/api-tokens)에 로그인한 뒤 API Token을 만드세요.
2. 계정에 사용 가능한 결제 수단이나 충분한 크레딧이 있는지 확인하세요.
3. 토큰을 복사해 안전하게 보관하세요.

::: warning API Token 보안
API Token을 커밋하거나, 스크린샷에 포함하거나, 누구와도 공유하지 마세요. 토큰이 유출되면 즉시 폐기하고 Replicate 콘솔에서 새 토큰을 만드세요.
:::

## AIRI에서 설정하기

1. **설정 → 제공자 → Artistry → Replicate**를 여세요.
2. API Token을 붙여넣으세요.
3. 모델 ID를 입력하세요. AIRI의 기본값은 `black-forest-labs/flux-schnell`입니다. 다른 모델을 선택하는 경우 Replicate 모델 페이지에 표시된 정확한 ID를 사용하세요.
4. 필요에 따라 기본 종횡비(기본값 `16:9`)와 추론 단계 수(기본값 4)를 설정하세요.

## 설정 확인

1. **설정 → 모듈 → Artistry**를 열고 **Replicate.ai (Cloud)**를 선택하세요.
2. **설정 → 모듈 → 의식**에서 도구/함수 호출을 지원하는 채팅 모델을 선택하세요.
3. 채팅으로 돌아가 AIRI에게 민감하지 않은 이미지를 생성해 달라고 요청하세요.
4. 이미지가 반환되면 토큰, 모델 ID, 계정 할당량, 도구 호출이 모두 정상 동작하는 것입니다.

## 문제 해결

인증이 실패하면 토큰 전체가 빠짐없이 붙여넣어졌는지 확인하세요. 요청이 거부되면 계정 할당량, 모델 접근 권한, 모델 ID를 확인하세요. 결과가 예상과 다르면 해당 모델이 지원하는 종횡비와 매개변수 범위를 확인한 뒤 추론 단계를 조정하거나 다른 모델을 선택하세요.
