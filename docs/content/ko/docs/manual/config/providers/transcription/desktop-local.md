---
title: 데스크톱 로컬 음성 인식 (ASR/STT, 사용 불가)
description: 데스크톱 로컬 음성 인식은 아직 설정할 수 없습니다
---

App (Local) 음성 인식은 아직 사용할 수 없습니다. AIRI 설정 페이지에는 현재 Work in Progress 플레이스홀더만 표시되어 모델을 준비하거나 활성화할 수 없습니다.

::: warning 사용 불가
아직 실제 사용 환경 구성에 이 제공자를 사용하지 마세요. 현재 사용 가능 여부를 명확히 알리기 위해서만 문서화되어 있습니다.
:::

## 사용 가능한 대안

지원되는 브라우저에서 [Web Speech API](./web-speech-api.md)를 사용하거나, 지원되는 클라우드 전사 제공자를 선택하세요.
