---
title: 공식 전사 제공자 (ASR/STT)
description: AIRI에서 공식 실시간 음성 인식 사용하기
---

공식 전사는 현재 AIRI 세션을 사용하므로 서드파티 API Key가 필요하지 않습니다.

::: info 왜 AIRI 공식 음성 인식을 선택하나요?
이미 공식 AIRI 제공자를 사용하고 있고 실시간 음성 입력을 빠르게 활성화하고 싶다면, 이 옵션을 먼저 시도해 볼 수 있습니다.
:::

## 계정에 로그인하기

1. AIRI 계정으로 로그인하세요.
2. 현재 세션에서 공식 전사 제공자를 사용할 수 있는지 확인하세요.

::: warning 계정과 오디오 데이터
실시간 인식은 오디오를 공식 서비스로 전송합니다. 민감한 정보가 포함된 테스트 오디오를 사용하지 말고, 계정 세션 정보를 공유하지 마세요.
:::

## AIRI에서 설정하기

1. **설정 → 제공자 → 전사 → 공식 전사 제공자**를 여세요.
2. 로그인한 계정에서 제공자 페이지를 사용할 수 있는지 확인하세요. 이 페이지에는 활성 모델 선택기가 없습니다.
3. **설정 → 모듈 → 청각**을 열고 **공식 전사 제공자**를 선택한 뒤 **Auto**를 선택하세요. 현재 제공자는 `Auto` 모델만 제공합니다.

## 설정 확인

1. AIRI가 마이크를 사용하도록 허용하고 짧은 음성 입력을 해 보세요.
2. 전사 결과가 표시되면 제공자가 올바르게 설정된 것입니다.

## 문제 해결

모델을 사용할 수 없다면 로그인되어 있는지, AIRI가 서비스에 연결할 수 있는지, 계정에 사용 가능한 크레딧이 있는지 확인하세요. 전사 결과가 표시되지 않으면 운영 체제에서 AIRI의 마이크 권한을 확인하세요.
