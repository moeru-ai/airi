---

이 페이지에서는 OpenAI 호환 전사 API를 설정합니다. 저장한 뒤 **설정 → 모듈 → 청각**에서 제공자와 모델을 선택하고 마이크 입력을 테스트하세요.

::: info 왜 ASR/STT에 OpenAI 호환 API를 사용하나요?
전사 제공자가 OpenAI 전사 API를 구현하고 있다면, 이 가이드를 따라 AIRI에 연결하세요. API 주소가 `/v1`로 끝나거나 키가 `sk-`로 시작한다고 해서 호환성이 보장되는 것은 아닙니다.
:::

## API Key 발급받기

1. 선택한 서비스 제공자의 관리 콘솔에 로그인하세요.
2. API Key 또는 Developer Settings 페이지에서 API Key를 생성하세요.
3. 키를 복사해 안전한 곳에 보관하세요.

::: warning API Key 보안
API Key를 커밋하거나, 스크린샷에 포함하거나, 누구와도 공유하지 마세요. 키가 유출되면 즉시 폐기하고 제공자 콘솔에서 새 키를 만드세요.
:::

## AIRI에서 설정하기

1. **설정 → 제공자 → 전사 → OpenAI Compatible**을 여세요.
2. API Key와 사용할 ASR/STT 모델 ID를 입력하세요.
3. 공식 OpenAI를 사용하려면 별도의 **OpenAI** 제공자를 선택하세요. **OpenAI Compatible** 제공자에는 기본 Base URL이 없으므로, 호환 서비스 문서에 안내된 완전한 API 루트를 입력하세요.

## 설정 확인

1. **설정 → 모듈 → 청각**에서 설정한 서비스 제공자와 모델을 선택한 뒤, 오디오 입력 장치를 선택하세요.
2. **Start Monitoring**을 클릭한 뒤 마이크에 대고 말하거나 오디오 클립을 재생하세요.
3. 전사 영역에 텍스트가 표시되는지 확인하세요. 인식이 부정확하면 감도를 조정하고 다시 테스트하세요.

## 문제 해결

텍스트 결과가 없으면 AIRI에 마이크 권한이 있는지 확인하세요. 호환 서비스를 사용하는 경우, 해당 서비스가 OpenAI 전사 API를 구현하고 입력한 모델 ID를 지원하는지 확인하세요.
