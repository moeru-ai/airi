채팅 모델은 AIRI의 "두뇌"입니다. 텍스트 응답을 생성하려면 채팅 모델을 사용할 수 있는 제공자 계정 또는 실행 중인 로컬 모델 서비스가 필요합니다.

## 사전 준비 사항

- AIRI가 설치되어 실행 중입니다.
- 클라우드 제공자의 경우, API Key를 생성했고 계정에서 선택한 채팅 모델을 사용할 수 있는지 확인했습니다.
- 로컬 제공자의 경우, 모델 서비스가 실행 중이며 AIRI가 실행되는 기기에서 접근할 수 있습니다.

## 제공자와 모델 설정

1. **설정 → 제공자 → 채팅**을 열고 사용할 제공자를 선택하세요.

어떤 제공자를 선택할지 확실하지 않다면 [OpenRouter](./providers/consciousness/openrouter.md), [DeepSeek](./providers/consciousness/deepseek.md), [OpenAI Compatible](./providers/consciousness/openai.md) 또는 로컬 [Ollama](./providers/consciousness/ollama.md)부터 시작하세요. 다른 채팅 제공자는 **제공자 → 채팅** 아래에 나열되어 있습니다.

2. API Key를 입력하세요. Base URL은 제공자 문서에서 다른 주소를 요구하는 경우에만 고급 설정에서 변경하세요.

3. 제공자 페이지에 표시되는 자동 유효성 검사 결과를 확인하세요. 제공자 필드는 수정하는 즉시 저장됩니다. 유효성 검사 방식은 제공자마다 다르며, 필드만 검사하거나, 모델 목록을 가져오거나, 소규모 실제 요청을 위한 **Ping API**를 제공하기도 합니다.

4. **설정 → 모듈 → 의식**을 열고 설정한 제공자와 모델을 선택하세요.

제공자가 지원하는 경우 AIRI가 모델 목록을 불러옵니다. 목록을 불러올 수 없고 필드에 직접 입력이 가능하다면, 제공자 공식 문서에 있는 정확한 모델 ID를 입력하세요.

5. 채팅 인터페이스로 돌아가 "Hello" 같은 짧은 메시지를 보내세요. 응답이 오면 제공자와 모델이 정상 동작하는 것입니다.

## 문제 해결

### 유효성 검사는 통과했지만 사용 가능한 모델이 없는 경우

먼저 제공자가 모델 목록 조회를 지원하는지 확인하세요. 일부 제공자는 모델 목록을 반환하지 않거나, API Key에 필요한 권한이 없을 수 있습니다. 이 경우 **설정 → 모듈 → 의식**에서 모델 ID를 직접 입력하세요. 모델 ID는 제공자 문서와 정확히 일치해야 합니다.

### 확인에 실패하거나 요청이 시간 초과되는 경우

API Key, Base URL, 계정 할당량, 네트워크 연결을 확인하세요. 로컬 서비스라면 서비스가 실행 중이고 AIRI가 설정된 주소에 접근할 수 있는지 확인하세요.

### AIRI가 응답하지 않는 경우

**설정 → 모듈 → 의식**에서 제공자와 모델이 모두 선택되어 있는지 확인하세요. 제공자 자격 증명을 저장해도 제공자가 자동으로 활성화되지는 않습니다.
