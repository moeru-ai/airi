---
title: 웹 검색 설정
description: Tavily로 AIRI가 대화 중에 최신 정보를 찾을 수 있게 설정
---

웹 검색을 사용하면 AIRI가 최신 정보나 낯선 정보를 인터넷에서 조회할 수 있습니다. 이 기능은 사용자의 Tavily API Key를 사용합니다. 도구가 활성화되어 있고 선택한 채팅 모델이 도구 호출을 지원하면, AIRI는 대화 중에 검색하고 반환된 출처를 인용할 수 있습니다.

## 사전 준비

- AIRI가 설치되어 실행 중입니다.
- Tavily 계정이 있고 [Tavily](https://tavily.com/) 콘솔에서 발급받은 API Key가 있습니다.
- 선택한 채팅 제공자와 모델이 도구 호출을 지원합니다.

::: warning API Key 보안
Tavily API Key는 현재 기기에만 저장해야 합니다. 저장소에 제출하거나, 다른 사람에게 보내거나, 캐릭터 카드·저널·스크린샷에 포함하지 마세요. 키가 유출된 것으로 의심되면 즉시 폐기하고 Tavily 콘솔에서 새 키를 만드세요.
:::

## 설정 단계

1. **설정 → 모듈 → Web Search**를 여세요.
2. **Enable Web Search**를 켜세요.
3. **Tavily API Key**에 API Key를 붙여넣으세요.
4. **Web search is ready to use!** 메시지가 표시되면 채팅으로 돌아갈 수 있습니다. 설정은 자동으로 저장되며 별도의 저장 버튼은 없습니다.

스위치를 끄거나 API Key를 지우면 AIRI는 더 이상 Tavily로 검색 요청을 보내지 않습니다.

## AIRI는 언제 검색하나요?

AIRI는 사용자가 검색을 요청할 때, 또는 뉴스, 가격, 최근 릴리스, 실시간 데이터, 갱신된 문서처럼 질문에 최신 정보가 필요할 때 검색할 수 있습니다.

더 집중된 결과를 얻으려면 목표와 범위를 명시적으로 말하세요:

- "AIRI 최신 안정 버전의 릴리스 노트를 검색하고 링크를 첨부해 줘."
- "Tavily 공식 문서에서 API Key 관련 안내를 찾아 줘."
- "`github.com/moeru-ai/airi`의 최근 일주일 업데이트만 검색해 줘."

검색 결과에는 출처 링크가 포함됩니다. 확보된 결과가 충분하지 않으면 AIRI는 추가로 검색하거나 불확실하다는 점을 분명히 밝혀야 합니다.

## 개인정보, 신뢰성 및 보안

검색할 때마다 질의 텍스트가 Tavily로 전송됩니다. API Key, 비밀번호, 액세스 토큰, 사적인 주소, 기타 민감한 정보를 포함하지 마세요. 검색 결과는 부정확하거나, 오래되었거나, 편향되어 있을 수 있습니다.

::: warning 중요한 정보는 직접 확인하세요
검색 결과는 참고 자료로만 AIRI에 제공되며 사용자의 원래 요청을 바꾸지 않습니다. 의료, 법률, 금융 정보는 링크된 출처를 직접 검토하고 공식 안내나 자격을 갖춘 전문가와 상의하세요.
:::

## FAQ

### Tavily는 설정 완료로 표시되는데 AIRI가 검색하지 않습니다

**Enable Web Search**가 켜져 있는지, 선택한 채팅 모델이 도구 호출을 지원하는지 확인하세요. 그런 다음 AIRI에게 "검색해서 출처 링크를 포함해 줘"라고 요청해 보세요. 그래도 검색하지 않으면 제공자의 도구 호출 지원 여부를 확인하세요.

### API Key, 권한 또는 할당량 오류가 발생합니다

Tavily 콘솔로 돌아가 키가 올바르고 여전히 유효한지 확인하고, 계정의 사용 가능한 크레딧이나 접근 권한을 확인하세요. 복사할 때 앞뒤 공백이나 줄바꿈이 들어가지 않게 하세요. 키를 변경했다면 새 키를 AIRI에 붙여넣으세요.

### 검색 결과가 부정확하거나 충분히 최신이 아닙니다

"최근 일주일만 확인해 줘", "공식 문서만 사용해 줘"처럼 기간, 지역, 선호하는 출처를 명시하세요. 중요한 정보는 인용된 링크를 열어 직접 확인하세요. 검색 결과는 전문가의 조언이나 독립적인 판단을 대체하지 않습니다.
